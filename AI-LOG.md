# AI-LOG.md

## Which sections did you generate with AI?

I used AI throughout the CSS development process, mainly as a guide and
development assistant rather than simply copying a finished solution.
The CSS was developed step by step through our conversation. I explained
what I wanted the page to look like, and the AI guided me through the
structure, styling, spacing, colors, and organization of the CSS. We
also worked on improving the visual design and adapting the color
palette, including the dark blue `#080736`.

The AI helped me understand what each part of the CSS was doing while we
were building it. Instead of generating everything independently and
using it without understanding it, I used the assistant to guide me
through the process and make decisions as we progressed.

## What did you modify and why?

I modified the CSS based on the visual result and the design decisions
we made during the process. The main modification was the color palette.
We changed the main color to the dark blue `#080736` and added related
colors to other sections so that the page had a more consistent
appearance.

I also adjusted values such as spacing, sizes, and other visual
properties when the result did not match what I wanted. These changes
were made because the first version was not necessarily the final visual
design, so the CSS needed to be adapted through testing and feedback.

## What was hardest to understand about the generated CSS?

The hardest part was understanding how several CSS properties could
interact with each other. Sometimes changing one property affected the
position, size, or appearance of another element. It was also difficult
at first to understand why certain layout and spacing decisions were
necessary.

The AI helped by explaining the CSS step by step and by answering
questions about individual properties. This made it easier to understand
the code instead of treating the generated CSS as something that I could
use without knowing how it worked.
